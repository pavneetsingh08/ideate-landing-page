# Techfest - An Aetherial Renaissance Landing Page

A stunning, modern landing page designed for Techfest (Asia's Largest Science and Technology Festival).

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fpavneetsingh08%2Fideate-landing-page)

## 🌐 Live Demo
*After deploying to Vercel, the live site URL will be updated here.*

## Features
- "An Aetherial Renaissance" theme implementation
- HTML5 Canvas particle background
- Pure CSS glowing orb and rotating rings animations
- Responsive design
- Custom typography (Cinzel and Montserrat)

## Usage
Open `index.html` in any modern web browser to view the landing page locally.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

# Techfest - An Aetherial Renaissance Landing Page

A stunning, modern landing page designed for Techfest (Asia's Largest Science and Technology Festival).

## Features
- "An Aetherial Renaissance" theme implementation
- HTML5 Canvas particle background
- Pure CSS glowing orb and rotating rings animations
- Responsive design
- Custom typography (Cinzel and Montserrat)

## Usage
Open `index.html` in any modern web browser to view the landing page.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
